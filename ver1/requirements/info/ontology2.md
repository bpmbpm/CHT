## ontology  
Упрощено: Онтология - это "Понятия о понятиях" (концептах). Толковый словарь терминов (концептов).

### 1 Base
Базовые (основные) составляющие:
- Онтология - это спецификация концептов
  - спецификация - точное описание, описание на формальном языке (форме), т.е. есть id объекта и операции с этим объектом (предикаты). 
  - концепт - образ, абстракция, шаблон и другие сущности - синонимы из Мира Идей (Платон). Онтология - Набор «концептуальных каркасов». 
- в простейшем случае Онтология описывает иерархию классов, т.е. таксономию. Таксономия - это иерархия терминов (классов), т.е. связь двух сущностей-понятий (концептов) через:
  - прямая: "являетсяРебенком" или subclass of (P279) - Х "является подклассом" Y
  - обратная: Y "является суперклассом" X, т.е. являетсяРодителем, 
  - чаще: используются имеетРебенка \ имеетеРодителя. Чечь про иерархию классов: дочерний класс или родительский (вышестоящий) 
### 2 extended
Дополнительные составляющие:
- кроме предиката иерархии subclass of вводятся другие предикаты и утверждения по предикатам (RBox) 
- важно различать предикаты для Мира идей (онтологии) и для Мира вещей (использование онтологии для формирования базы знаний)
  - ontology (TBox):
    - указание, что классы взаимноисключающиеся, например, через disjoint classes
    - свойства концептов Object Properties - связывают объекты между собой, привязывают к ним типы данных, такие как строки и числа (Data Properties) и др. 
  - not ontology (Abox):
    - instance - создание экземпляров
  - universal универсальные:
    - label - названия, описание концептов или их экземпляров
### 3 rule
Правила вывода вторичных утверждений из первичных (явно указанных) - reasoning (логический вывод), например, вывод внука (деда) по последовательности отцовства.

### 4 systax
Формализм логических утверждений, запись синтаксического триплета и т.п., т.е. синтаксис (алфавит) для передачи семантики (смысла)

Схема: 
- толковый словарь терминов, собранный как таксономия - Простейшая онтология (TBox, где TBox задает иерархию классов и описание, например, через label). 
- добавление в Простейшую онтологии других предикатов, кроме, "subclass of" и универсальных, формирование RBox, а также добавление правил вывода одних утверждений из других (rule, reasoning) - это создание Классической онтологии
