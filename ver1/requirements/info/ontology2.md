## ontology  
Упрощено: Онтология - это "Понятия о понятиях" (концептах). Толковый словарь терминов (концептов).

### 1 Base
Базовые составляющие:
- Онтология - это спецификация концептов
  - спецификация - точное описание, описание на формальном языке (форме), т.е. есть id объекта и операции с этим объектом (предикаты). 
  - концепт - образ, абстракция, шаблон и другие сущности - синонимы из Мира Идей (Платон) 
- в простейшем случае Онтология описывает иерархию классов, т.е. таксономию. Таксономия - это иерархия терминов (классов), т.е. связь двух сущностей-понятий (концептов) через
  - прямая: "являетсяРебенком" или subclass of (P279) - Х "является подклассом" Y
  - обратная: Y "является суперклассом" X, т.е. являетсяРодителем, 
  - чаще: используются имеетРебенка \ имеетеРодителя. Чечь про иерархию классов: дочерний класс или родительский (вышестоящий) 
### extended
- кроме предиката иерархии subclass of вводятся другие предикаты
- важно различать предикаты для Мира идей (онтологии) и для Мира вещей (использование онтологии для формирования базы знаний)
  - ontology:
    - указание, что классы взаимноисключащиеся 
  - not ontology:
    - instance - создание экземпляров
  - universal универсальные:
    - label - названия, описание концептов или их экземпляров
### rule
Правила вывода вторичных утверждений из первичных (явно указанных) - reasoning, например, вывод внука (деда) по последовательности отцовства.
